# Доступ по SSH

[English](README.md) | **Русский**

ScreenSender показывает вам экран. Эта папка добавляет второй путь на тот же ПК с Windows: SSH-сервер,
чтобы Claude Code (или вы) с другого компьютера мог выполнять там команды, копировать файлы и чинить
сам ScreenSender, если тот остановится. Это отдельная часть, она работает и без ScreenSender.

## Что здесь

- `install-server.ps1` запускается на ПК от имени администратора. Ставит OpenSSH Server из Windows,
  запускает его вместе с Windows, разрешает вход только по ключу, делает оболочкой PowerShell, открывает
  порт в брандмауэре, добавляет и удаляет ключи клиентов.
- `setup-client.ps1` запускается на компьютере, с которого подключаетесь. Создаёт ключ, прописывает
  короткие имена ПК в `~/.ssh/config` и объясняет Claude Code на этом компьютере, как работать с ПК.
- `remote.ps1` выполняет код PowerShell на ПК по первому рабочему маршруту, без экранирования кавычек
  и с читаемым выводом.

## Маршруты

До ПК можно добраться тремя путями; настройте сколько нужно:

| Имя | Маршрут | Что нужно |
|---|---|---|
| `home-ts` | [Tailscale](https://tailscale.com) — частная сеть между вашими устройствами | Tailscale на обоих компьютерах |
| `home` | внешний IP или имя в динамическом DNS | проброс порта на роутере |
| `home-lan` | та же локальная сеть | ничего |

Tailscale не требует открытых портов и переживает смену IP, но в некоторых сетях VPN-трафик блокируют;
тогда выручает внешний адрес. Маршруты друг от друга не зависят.

## Настройка

На ПК, в PowerShell от имени администратора, в папке репозитория:

```
powershell -ExecutionPolicy Bypass -File ssh\install-server.ps1
```

На своём компьютере, в папке репозитория (права администратора не нужны); укажите те маршруты, что есть:

```
powershell -ExecutionPolicy Bypass -File ssh\setup-client.ps1 -User <учётная запись Windows на ПК> -LanHost 192.168.1.20 -TailscaleHost home-pc -PublicHost my.ddns.net -PublicPort 22022
```

Скрипт напечатает строку с `-PublicKey "ssh-ed25519 ..."` — выполните её на ПК от имени администратора.
Если вы не рядом с ПК, вставьте её через ScreenSender (скопируйте, затем Ctrl+V на странице ScreenSender).
Запустите `setup-client.ps1` ещё раз — он покажет, какие маршруты работают.

## Использование

```
ssh home-lan                                   # интерактивный PowerShell на ПК
& ssh\remote.ps1 'Get-Service sshd'            # одна команда, лучший маршрут
Get-Content job.ps1 -Raw | & ssh\remote.ps1    # скрипт
scp report.pdf home-lan:Desktop/               # файлы
```

Команды выполняются от имени администратора и без рабочего стола: программы, запущенные по SSH, на
экране не появляются.

## Безопасность

- Вход только по ключу, пароли отключены.
- У того, у кого есть ключ с вашего компьютера, есть права администратора на ПК. Если компьютер потерян,
  удалите его ключ на ПК: `ssh\install-server.ps1 -RemoveKey claude@<тот компьютер>`.
- Чтобы забыть ПК на своём компьютере: `ssh\setup-client.ps1 -Name home -Remove`.
- Claude Code спрашивает разрешение перед каждой командой; для команд на ПК так и оставьте.
